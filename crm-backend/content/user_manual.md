# B2B CRM 系统使用说明书

> 面向日常使用者（销售、市场、销售管理、系统管理员）  
> 适用范围：当前 Web 端 MVP（线索 → 客户 → 商机）  
> 说明：界面上能看到哪些菜单，取决于您的角色权限；看不到的菜单表示当前账号无权访问。

---

## 1. 系统能帮您做什么

本系统用于管理 B2B 销售过程，核心链路是：

**线索 → 客户 → 商机**

您可以：

- 录入、导入、分配、认领线索，并转化为客户  
- 维护客户档案、联系人与跟进记录  
- 用看板/列表推进商机阶段，完成赢单或输单结案  
- 查看仪表盘与销售目标达成情况  
- 处理待办与审批  
- （管理员）配置组织、角色、商机阶段、公海规则、字典与审计日志

## 2. 登录与退出

### 2.1 登录

1. 打开系统登录页（标题为 **B2B CRM**）。  
2. 输入 **用户名**、**密码**。  
3. 点击 **登录**。  
4. 登录成功后，默认进入 **仪表盘**。

若提示登录失败，请核对账号密码，或联系管理员确认账号是否启用/锁定。

### 2.2 退出登录

1. 点击页面右上角的 **头像 / 姓名**。  
2. 在下拉菜单中选择 **退出登录**。  
3. 系统将返回登录页。

### 2.3 界面总览

登录后，页面大致分为：

| 区域 | 说明 |
|------|------|
| 左侧菜单 | 按权限展示功能入口，可折叠 |
| 顶部栏 | 显示业务提示「线索 → 客户 → 商机」、通知铃铛、个人菜单 |
| 中间内容区 | 当前功能的列表、详情、表单 |

左侧常见菜单：

- 仪表盘  
- 线索  
- 客户  
- 商机  
- 目标  
- 报表  
- 待办审批  
- 系统管理（组织用户、角色权限、商机阶段、公海规则、数据字典、审计日志）

## 3. 仪表盘

进入 **仪表盘** 后，可快速了解经营概况：

- **线索** 数量  
- **客户** 数量  
- **进行中商机** 数量  
- **赢单金额**  
- **销售漏斗**：各阶段商机数量与金额  
- **目标达成**：目标值、实际值与完成进度  

适合每天开工时先看一眼：今天有多少在途商机、目标完成得怎样。

## 4. 线索管理

路径：左侧菜单 → **线索**

### 4.1 我的线索 / 公海

列表上方有两个页签：

- **我的线索**：您可见范围内的私有线索  
- **公海**：无人跟进或已退回公海的线索，可 **认领**

常用操作：

- **搜索**：按关键字搜索线索  
- **状态筛选**：新建 / 已分配 / 跟进中 / 已转化 / 无效 / 公海  
- **新建线索**  
- **导入**（CSV/Excel）  
- 勾选多条后 **批量分配**（填写目标负责人用户 ID）  

### 4.2 新建 / 编辑线索

点击 **新建线索**（或详情页 **编辑**），填写：

| 字段 | 说明 |
|------|------|
| 线索/公司名 | 必填 |
| 联系人 | 可选 |
| 手机 / 邮箱 | 可选 |
| 来源 | 官网 / 展会 / 转介绍 / 导入 |
| 行业 | 可选 |

保存后进入该线索详情页。

### 4.3 批量导入

1. 在线索列表点击 **导入**。  
2. 点击或拖拽上传 **CSV/Excel** 文件。  
3. 系统提交异步导入任务，页面展示任务进度（成功 / 失败 / 总计）。  
4. 完成后返回列表查看结果。

### 4.4 线索详情与跟进

详情页可查看资料，并执行：

- **编辑**  
- **转化为客户**（成功后自动跳转到新客户详情）  
- **作废**（需填写作废原因）  
- **退回公海**  

页签：

- **资料**：联系人、手机、邮箱、来源、行业、负责人、公海状态、最近跟进时间等  
- **跟进**：记录拜访、电话、邮件、微信等（见第 9 章）  

### 4.5 公海认领

在 **公海** 页签中，对目标线索点击 **认领**，认领成功后线索进入您的私有列表。若提示失败，可能是领取配额不足或规则限制，请联系销售经理/管理员。

## 5. 客户管理

路径：左侧菜单 → **客户**

### 5.1 我的客户 / 公海

- **我的客户**：可搜索、查看详情、新建客户  
- **公海**：可对公海客户点击 **领取**  

### 5.2 新建 / 编辑客户

填写客户基本信息后保存。客户详情页可继续维护联系人与跟进。

### 5.3 客户详情

顶部操作：

- **编辑**  
- **转移**：变更负责人（填写目标用户 ID）  
- **锁定 / 解锁**：锁定后用于保护关键客户（按公司规则使用）  

页签：

#### 资料

行业、区域、生命周期、负责人、最近跟进时间等。

#### 联系人

1. 点击 **新增联系人**。  
2. 填写姓名（必填）、手机、职务、邮箱。  
3. 保存后可在列表中查看；主联系人会有标记。  

#### 时间线 / 跟进

与线索相同，可在此持续记录客户互动（见第 9 章）。

### 5.4 从线索到客户（推荐流程）

1. 在线索中完善信息并持续跟进。  
2. 确认有效后，在线索详情点击 **转化为客户**。  
3. 进入客户详情，补充联系人与后续商机。  

---

## 6. 商机管理

路径：左侧菜单 → **商机**

### 6.1 看板与列表

顶部可切换：

- **看板**：按商机阶段分列展示，适合日常推进  
- **列表**：表格查看商机、客户、金额、阶段、负责人、预计成交日  

点击 **新建商机** 创建新商机。

### 6.2 在看板上推进阶段

1. 在看板卡片中打开阶段下拉框。  
2. 选择目标阶段。  
3. 确认「推进阶段」后，卡片移动到对应列。  

> 若提示「请先在系统管理中配置商机管道阶段」，请联系管理员配置默认管道。

### 6.3 商机详情

顶部可：

- **推进阶段**（下拉选择）  
- **赢单**（结案）  
- **输单**（必须填写输单原因）  
- **编辑**  

页签：

#### 资料

客户、金额、阶段、状态、预计成交、负责人、竞争对手、输单原因等。

#### 产品明细

1. 点击 **添加产品行**。  
2. 填写产品名、SKU、数量、单价（金额自动按数量×单价计算）。  
3. 保存产品行。  

#### 跟进

记录商机相关拜访/通话等。

### 6.4 赢单 / 输单建议

- 已明确签约 → **赢单**  
- 明确丢单 → **输单** 并填写原因（便于复盘）  
- 过程中只推进阶段、不要过早结案

## 7. 目标与报表

### 7.1 销售目标

路径：**目标**

- 查看已设定的个人/部门销售目标  
- 点击新建，填写：  
  - 范围类型：个人 / 部门  
  - 范围 ID  
  - 指标：金额 / 数量  
  - 周期：月 / 季度  
  - 周期键：如 `2026-10`  
  - 目标值  

仪表盘会汇总展示目标达成进度。

### 7.2 报表

路径：**报表**

用于查看经营相关统计（以界面实际报表项为准）。导出等操作若不可用，通常是权限不足。

---

## 8. 待办、审批与通知

### 8.1 待办审批

路径：**待办审批**

两个页签：

- **待办**：查看事项，完成后点击 **完成**  
- **审批**：对待审批项执行 **通过** / **驳回**  

建议每天处理一次，避免超时影响业务流转。

### 8.2 通知

点击右上角 **铃铛**，进入通知列表，查看系统提醒（跟进提醒、审批等）。

---

## 9. 如何写跟进记录

在线索、客户、商机详情的 **跟进**（或时间线）页签中：

1. 选择跟进类型：拜访 / 电话 / 邮件 / 微信 / 其他  
2. 可选填写主题  
3. 必填跟进内容  
4. 点击 **写跟进**  

写跟进有助于：

- 团队协作时快速了解历史  
- 公海回收规则判断「是否及时跟进」  
- 销售经理复盘过程

## 10. 系统管理（管理员）

路径：左侧 **系统管理**（需具备设置相关权限）

### 10.1 组织用户

- 维护 **部门树**（可新增部门）  
- 维护 **用户账号**（可新建用户：用户名、姓名、密码等）  

### 10.2 角色权限

- 配置角色及其可访问的菜单/操作权限  
- 控制谁能看线索、客户、商机，谁能管理系统  

### 10.3 商机阶段

- 配置商机管道与阶段顺序  
- 看板按默认管道的阶段展示  

### 10.4 公海规则

- 配置线索/客户进入公海、回收与领取相关规则  
- 规则生效后，超时未跟进的数据可能自动进入公海  

### 10.5 数据字典

- 维护来源、行业、输单原因等可配置选项  
- 保证各模块下拉值统一  

### 10.6 审计日志

- 查看关键操作与登录相关日志  
- 用于安全审计与问题追溯

## 11. 推荐日常操作路径

### 销售代表：一天怎么用

1. 打开 **仪表盘**，看漏斗与目标。  
2. 处理 **待办审批** 与通知。  
3. 去 **线索**：跟进私有线索，必要时从公海认领。  
4. 有效线索执行 **转化为客户**。  
5. 在 **客户** 中补充联系人并写跟进。  
6. 创建/推进 **商机**，临近成交时维护产品明细与预计成交日。  
7. 成交后 **赢单**；明确丢单则 **输单** 并写原因。  

### 销售经理：重点看什么

1. 仪表盘漏斗与团队目标达成。  
2. 公海积压与线索分配是否合理。  
3. 审批是否积压。  
4. 输单原因与阶段停留是否异常。  

### 市场专员：重点做什么

1. **导入** 活动/渠道线索。  
2. 配合经理完成分配。  
3. 关注来源字段是否填写规范，便于后续统计。  

### 管理员：上线前后检查

1. 组织与用户是否建好。  
2. 角色权限是否按岗位分配。  
3. 商机阶段是否配置且有默认管道。  
4. 公海规则、字典是否就绪。  
5. 抽查审计日志是否有记录。

## 12. 常见问题

**Q1：登录后左侧菜单很少？**  
A：按角色授权。请联系管理员开通对应权限（如 `lead:read`、`account:read` 等）。

**Q2：商机看板是空的？**  
A：可能还没有进行中的商机，或尚未配置商机阶段。先新建商机，或请管理员配置管道。

**Q3：转化客户失败？**  
A：检查线索信息是否完整、账号是否有转化权限，或该线索是否已转化/作废。

**Q4：公海认领失败？**  
A：可能触发了领取配额或公海规则限制，请联系销售经理/管理员。

**Q5：客户被锁定后怎么办？**  
A：有权限的用户可在客户详情点击 **解锁**；无权限时请找负责人或管理员。

**Q6：支持哪些浏览器？**  
A：建议使用较新版本的 Chrome / Edge；Safari 近两个大版本通常也可。

## 13. 使用小贴士

1. **先跟进、再转化**：线索信息不全时先完善再转客户。  
2. **阶段推进要真实**：不要为了好看把阶段跳得太快。  
3. **输单必填原因**：方便团队复盘。  
4. **公海不是垃圾桶**：退回前确认确实无法跟进。  
5. **敏感操作可审计**：分配、结案、权限变更等请规范操作。
