# CRM 系统需求说明

> 版本：v0.1  
> 范围：B2B 销售型 CRM（线索 → 客户 → 商机 → 合同 → 售后）  
> 状态：初稿，可作为产品/研发基线

---

## 1. 用户角色

| 角色 | 说明 | 主要职责 |
|------|------|----------|
| 系统管理员 | 租户级配置与运维 | 组织架构、角色权限、字段/流程配置、集成与审计 |
| 销售总监 / 销售经理 | 团队管理与业绩管控 | 目标分解、商机审批、漏斗复盘、团队绩效 |
| 销售代表 | 一线获客与跟进 | 线索转化、客户维护、商机推进、活动记录 |
| 市场专员 | 获客与活动运营 | 线索导入/分配、活动管理、渠道效果追踪 |
| 客服 / 客户成功 | 售后与续约 | 工单处理、客户健康度、续约/增购跟进 |
| 财务对接人（只读/半写） | 回款与合同财务核对 | 查看合同金额、回款计划、开票状态 |
| 只读观察者 | 高管/审计只读 | 仪表盘与报表查看，无写权限 |

### 1.1 权限原则

- **基于角色（RBAC）**：菜单、对象、字段、操作四层授权。
- **数据范围**：本人 / 本部门 / 本部门及下级 / 全公司；支持「负责人 + 协作人」可见。
- **字段级控制**：金额、手机号等敏感字段可脱敏或禁止导出。

## 2. 核心用例

### UC-01 线索获取与分配

- **参与者**：市场专员、销售经理、销售代表  
- **主流程**：导入/表单获客 → 去重校验 → 按规则或手动分配 → 销售认领/跟进  
- **备选**：重复线索合并；超时未跟进自动回收公海  

### UC-02 线索转化客户

- **参与者**：销售代表  
- **主流程**：完善线索信息 → 确认有效 → 一键转化为客户（及可选联系人）→ 关闭线索  
- **备选**：无效线索标记原因并归档  

### UC-03 客户与联系人维护

- **参与者**：销售代表、客服  
- **主流程**：新建/编辑客户 → 维护多联系人与角色 → 记录拜访/通话/邮件 → 查看时间线  
- **备选**：客户合并；客户转交（变更负责人）  

### UC-04 商机全生命周期

- **参与者**：销售代表、销售经理  
- **主流程**：从客户创建商机 → 阶段推进（含必填校验）→ 赢单/输单结案 → 关联合同  
- **备选**：阶段回退需审批；输单必填原因  

### UC-05 合同与回款

- **参与者**：销售代表、销售经理、财务对接人  
- **主流程**：基于赢单商机创建合同 → 审批生效 → 维护回款计划 → 登记回款/开票状态  
- **备选**：合同变更/作废走审批流  

### UC-06 公海池管理

- **参与者**：销售代表、销售经理  
- **主流程**：满足规则的客户/线索入公海 → 销售领取（有配额）→ 超时未跟进再回收  
- **备选**：经理强制回收/分配  

### UC-07 目标与业绩看板

- **参与者**：销售经理、销售总监、只读观察者  
- **主流程**：设定团队/个人目标 → 实时汇总漏斗与达成率 → 下钻到商机明细  
- **备选**：导出报表；按时间/产品/区域切片  

### UC-08 工单与售后跟进

- **参与者**：客服、客户成功、销售代表  
- **主流程**：创建工单并关联客户 → 分派处理 → 关闭并回访 → 触发续约/增购提醒  
- **备选**：SLA 超时升级  

### UC-09 系统配置与审计

- **参与者**：系统管理员  
- **主流程**：配置组织/角色/字段/阶段/审批 → 查看操作日志与登录日志  
- **备选**：启用/停用用户；重置权限模板

## 4. 非功能需求

### 4.1 性能

| 指标 | 目标 |
|------|------|
| 常规列表页 P95 响应 | ≤ 1.5s（万级数据过滤场景） |
| 详情页 P95 响应 | ≤ 800ms |
| 并发在线用户 | ≥ 500（首期可按租户规模调整） |
| 批量导入 | 1 万行线索 ≤ 5 分钟（异步任务） |
| 报表查询 | 常用报表 P95 ≤ 3s；复杂报表可异步 |

### 4.2 可用性与可靠性

- 核心业务（客户/商机/合同写操作）可用性目标：**≥ 99.5%**（月度）。
- 支持滚动发布；关键写路径具备幂等与失败重试。
- 日备份；RPO ≤ 24h，RTO ≤ 4h（首期目标，可按 SLA 升级）。

### 4.3 安全与合规

- 全站 HTTPS；密码加盐哈希；会话超时与强制登出。
- RBAC + 数据范围 + 字段脱敏；导出需授权并可审计。
- 防越权（水平/垂直）、CSRF、注入类基础防护。
- 操作日志保留 ≥ 180 天；登录失败锁定策略。
- 支持个人敏感信息最小化采集与可配置留存策略。

### 4.4 可扩展与集成

- 多租户或单租户可部署（按交付形态选定）。
- 模块化：线索/客户/商机/合同/工单可分期上线。
- 提供 REST API；预留 Webhook 与主流 IM/邮件/日历集成点。

### 4.5 易用性与体验

- 桌面 Web 优先；关键列表/详情支持响应式访问。
- 关键路径（建线索/跟进/推进商机）≤ 3 次主要点击完成。
- 中文界面；表单校验即时反馈；空状态与引导文案齐全。

### 4.6 可维护性

- 配置优先于硬编码（字段、阶段、审批、通知）。
- 结构化日志与链路追踪 ID；关键业务指标可观测。
- 环境分离：开发 / 测试 / 生产；配置与密钥不入库。

### 4.7 兼容性

- 浏览器：Chrome / Edge 近两个大版本；Safari 近两个大版本。
- 时区与日期：默认 Asia/Shanghai，可配置。
- 附件：常见 Office / PDF / 图片格式；单文件大小上限可配置（默认 20MB）。

## 5. 范围边界（首期建议）

**纳入首期（MVP）**

- 角色权限、线索、客户/联系人、商机管道、基础跟进、简单目标看板、审计日志。

**可二期**

- 完整合同回款、工单 SLA、市场活动 ROI、高级自动化、开放 API/SSO、客户健康度。

**明确不做（除非另行立项）**

- ERP/进销存全量替代、复杂计费引擎、呼叫中心 CTI 深度定制、独立移动 App（可用响应式先替代）。

---

## 6. 验收要点（摘要）

1. 各角色登录后仅能访问授权菜单与数据范围。  
2. 线索可完成「导入 → 分配 → 跟进 → 转化客户」闭环。  
3. 商机可按配置阶段推进，并完成赢单/输单结案。  
4. 公海回收与领取配额规则生效且可审计。  
5. 关键列表/详情满足性能指标抽样验收。  
6. 敏感操作与导出留有完整审计记录。
